# Delos 1 ETH graduation test

Run this in an isolated team environment with fresh Delos-controlled accounts. The **TEST LAUNCH** label does not make Robinhood mainnet transactions free or reversible. Do not use old Census keys or personal wallet files.

1. Review the source and locked dependencies before executing them. Deploy a fresh V4 stack with independently verified PoolManager, quoter, StateView, WETH, treasury and keeper addresses. Record transaction hashes and deployed contract addresses; verify each contract and its wiring on an explorer.
2. Configure the frontend with that exact V4 stack, chain ID 4663, deployment start block and HTTPS indexer URL. Configure the indexer with the same curve, factory, hook and PoolManager addresses. Confirm `/health` reports the expected chain, V4 product, current finalized block and healthy database before opening the test site.
3. Launch an ETH-anchored meme coin with no creator buy. Confirm the launch transaction, creator, token address, 1 ETH `graduationQuote`, fee setting, and indexer registration agree with chain state. Repeat with an optional creator buy only if the creator-buy factory has been separately deployed and authorized.
4. Use separate test wallets for buys and sells. Confirm the 3-second launch-window buy tax for a nonexempt wallet, then the ordinary 2% base fee afterward. On the curve, verify fee events and balances show 90% of the base fee to the Delos treasury and 10% to the creator. If holder reflection is selected, verify it is additional and credited to the vault.
5. Buy in small increments until the **net** real quote reserve reaches 1 ETH. Confirm the final buy caps or refunds excess input, graduation triggers, the pool ID matches the canonical V4 pool, and liquidity is permanently custodied. If graduation is deferred, record the reason and verify the retry path.
6. Buy and sell through the site after graduation. Compare quotes, receipts, wallet balances, hook events and fee destinations. The canonical pool should charge the 2% base fee on both sides, with 30% of that fee to Delos and 70% to the creator, plus any elected holder reflection. Check that external pools are outside this hook's fee coverage; the site must identify the canonical pool.
7. Verify that every chart candle and the buy/sell feed come from indexed transactions, that explorer links resolve to those transactions, and that curve and pool trades both appear. Disconnect the indexer and confirm the page shows an unavailable state instead of synthetic prices.

Record the deployment addresses, wallet roles, transaction hashes, observed balances, fee arithmetic, and any discrepancies in a separate test report. Do not treat the code or this plan as a completed security audit or production sign-off.
