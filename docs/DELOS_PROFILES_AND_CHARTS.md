# Delos public profiles and trading chart

Public profiles live in the indexer's Postgres database. Run the new Prisma migration and point `VITE_INDEXER_URL` at the deployed indexer. A wallet signs each edit; the server verifies the signature against the configured chain, prevents nonce replay and rejects older signed edits. Display name, bio and links are public. Profile images and banners use the existing signed, quota-limited `/api/upload` endpoint and therefore require the Vercel Blob and KV variables already used by launch images. If that store is unconfigured, text edits still work, but images cannot be hosted. Moderators can set `WalletProfile.hidden=true` in Postgres to suppress an abusive profile.

The indexer's `/coins/:address/candles` endpoint aggregates canonical curve and graduated-pool `Trade` rows into 1m, 5m, 15m, 1h, 4h or 1d OHLCV bars. Quote volume includes the full input on buys and the gross output on sells. The API limits requests to 500 bars and returns no bar for intervals without trades. The token page displays candles, quote volume, SMA 20/50, crosshair OHLCV, interval/zoom/history controls and the existing live buy/sell feed. This is first-party Delos data, so it covers tokens before and after graduation without depending on an external chart provider indexing the chain.

The on-platform buy/sell panel remains beside the chart. It uses the bonding curve before graduation and the canonical hooked V4 pool after graduation, with protected `minOut` and the existing fee display. The changed button names the selected side and token.

Before exposing the feature publicly, deploy the indexer migration and frontend together; test profile edits (including contract wallets), image uploads, link validation, moderation, multiple candle intervals, thinly traded periods, graduation, and both buy/sell paths on the team's isolated deployment. The chart needs a running indexer; it shows a clear unavailable state when one is not configured. The endpoint uses indexed finalized events and can lag the newest chain tip by the indexer's confirmation window.
